# Лабораторная работа: Циклы с пред- и постусловием

## Автор
Карнаухов Фёдор (Вариант 7)

## Цель
Освоение базового синтаксиса C++ и применение циклов с предусловием и постусловием при решении прикладных задач.

## Описание
Программа рассчитывает остаточное давление газа в баллоне (или сосуде) после серии циклов «накачки-сброса» (качаний). 

Расчет производится по формуле:
`P_ост = P_нач * (V_баллона / (V_баллона + V_рабочий))^N`
где `N` — количество качаний.

В программе реализованы два независимых цикла:
1. Цикл с предусловием (`while`) — выполняет расчет до достижения количества качаний значения 50, с шагом 10.
2. Цикл с постусловием (`do-while`) — продолжает расчет до достижения количества качаний значения 260, с шагом 50. Гарантированно выполняется хотя бы один раз.

## Исходные данные
Пользователь вводит с клавиатуры:
- **working Volume** — рабочий объём (вводится с клавиатуры, тип `double`).
- **number Of Swings** — начальное количество качаний (вводится с клавиатуры, тип `double`).

Заданные константы в коде:
- Объём баллона (`container`) = 15
- Начальное давление (`pressure`) = 760 мм рт. ст.

## Ожидаемые результаты
Программа выводит на экран для каждого шага обоих циклов:
- `residual Pressure` — рассчитанное остаточное давление.
- `number Of Swings` — текущее количество качаний на данном шаге.

Сначала выводятся результаты цикла с предусловием (от введенного значения до 50), затем результаты цикла с постусловием (начиная от значения, на котором остановился первый цикл, до 260).
